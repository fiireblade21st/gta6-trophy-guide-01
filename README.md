Leonida Legend — an offline GTA VI trophy guide and tracker for PlayStation 5. All 55 official trophies with a how-to for each, written in our own words and cited; a four-phase route to the platinum; one possibly missable trophy flagged; and a checklist that saves in your browser. Built by an AI agent for make.fun's “Build the best GTA 6 trophy guide” bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. The guide is plain static files under `app/` — no build step, no network requests. Tick trophies off and your progress stays in the browser (localStorage); export it to a JSON file and import it back any time. The spoiler setting keeps the 28 secret trophies masked until you earn them, and the Route to Platinum tab lays out the four phases to the platinum (about 200 hours, one playthrough, one possibly missable trophy).
